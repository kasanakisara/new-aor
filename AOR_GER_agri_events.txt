# ============================================================
# 粮食系统地区工作 —— 事件链
# 第一层 GER_SPD.1 ：选择地区（由决议 GER_open_regional_food_work 触发）
# 第二层 GER_SPD.2 ~ .11 ：各地区选择 mission（按地区分类决定可用项）

# 【地区分类】（用户定稿，左翼即 SPD）
#   左翼核心区  = SPD核心区 → 粮食税 + 城乡交换
#      石勒苏益格-荷尔施泰因、萨克森
#   右翼核心区  = 敌方核心区 → 征粮 + 城乡交换
#      巴伐利亚、波美拉尼亚
#   摇摆区                 → 征粮 + 城乡交换
#      威斯特伐利亚（威斯特法伦）、西里西亚、梅克伦堡、法兰克福（黑森）、
#      符腾堡（巴登—符腾堡）、普鲁士（东普鲁士）
# 未纳入（无对应 tag，不管）：柏林、鲁尔、汉诺威、莱茵兰、威悉—埃姆斯、
#                             勃兰登堡、巴登、图林根
# ============================================================
