# 抽牌先决条件：冷却与政治点数花费（50 基础花费，按 5 点步长兼容减费）
AOR_tarot_not_on_cooldown = {
    OR = {
        NOT = { has_variable = AOR_tarot_draw_cooldown }
        check_variable = { AOR_tarot_draw_cooldown < 1 }
    }
}

AOR_tarot_has_enough_pp = {
    OR = {
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 1 } }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 6 } has_political_power > 4.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 11 } has_political_power > 9.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 16 } has_political_power > 14.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 21 } has_political_power > 19.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 26 } has_political_power > 24.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 31 } has_political_power > 29.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 36 } has_political_power > 34.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 41 } has_political_power > 39.99 }
        AND = { has_variable = AOR_tarot_draw_cost check_variable = { AOR_tarot_draw_cost < 46 } has_political_power > 44.99 }
        has_political_power > 49.99
    }
}
